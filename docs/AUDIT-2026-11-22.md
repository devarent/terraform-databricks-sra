## Perbaikan yang benar-benar diterapkan di repo ini

1. **README:** hapus badge dekoratif yang tidak menjelaskan SRA; pertahankan uraian upstream, batasan dukungan, dan disclaimer point-in-time. Tambahkan konteks fork, navigasi, lokasi modul dan tautan portfolio.
2. **Atlas reproducible:** [audit_repos.py](../scripts/audit_repos.py) dan [wrapper shell](../scripts/audit-repos.sh) membaca seluruh halaman repo, mengenali varian nama lisensi, menghitung hanya file workflow YAML, serta membedakan HTTP 404 dari error autentikasi/rate limit/network. Tidak menggunakan berkas `/tmp` bersama atau menulis ke repo remote.
3. **Validasi offline:** [test_audit_repos.py](../scripts/test_audit_repos.py) menguji API error handling, pagination, rendering, kesesuaian snapshot/atlas, tautan file lokal dan aturan gitignore. [validate.sh](../scripts/validate.sh) menjalankan tes, shell syntax dan diff checks; Terraform fmt dijalankan hanya jika tool tersedia, dengan skip eksplisit jika tidak.
4. **CI maintenance:** workflow baru menjalankan tes offline tanpa akun GitHub pemilik atau cloud credentials, dengan token read-only, timeout dan concurrency. Tidak menggantikan tes Terraform upstream.
5. **tfsec commenter:** ganti `checkout@main` dengan SHA checkout v4 yang diverifikasi melalui API, nonaktifkan penyimpanan credential Git, batasi permission default dan waktu job. PR dari fork dilewati karena tokennya tidak dapat menulis komentar. **Scanner tfsec tidak diganti dan PR fork belum mendapat scan dari workflow ini.** Migrasi ke scanner read-only untuk semua PR perlu evaluasi terpisah.
6. **Gitignore:** ganti blanket `*.hcl` dengan `.terraform.lock.hcl` untuk mempertahankan kebijakan lock-file lokal yang ada tanpa menyembunyikan HCL baru. Tambahkan ignore saved plan dan Python bytecode. Ini tidak membersihkan file yang sudah tracked atau riwayat Git.
7. **Kontribusi:** perluas panduan kontribusi, tambahkan template PR, EditorConfig dan Dependabot khusus GitHub Actions. Tidak membuat janji SLA atau mengganti kebijakan keamanan upstream.
8. **Dokumentasi workflow:** perbaiki nilai default `terraform_version` menjadi `1.x`, sesuai reusable workflow. Constraint HCL `~>1.0` berarti `>=1.0, <2.0`, **bukan** `1.0.x`; sintaks HCL tidak sama dengan npm semver pada input setup-terraform. Tidak ada alasan untuk menyeragamkan floor provider tanpa memeriksa kebutuhan setiap modul.

File upstream yang dimodifikasi diberi pemberitahuan perubahan. `LICENSE`, `NOTICE`, dependency manifest/lockfile, konfigurasi deployment, dan seluruh resource Terraform tetap utuh. GCP di checkout ini berisi panduan/gambar, bukan modul `gcp/tf`.
